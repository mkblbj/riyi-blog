# 关于日宜

**日宜找房｜短视频与 AI 时代的日本找房新选择**

> **移居日本找日宜。**

日宜找房，是由**上海日宜房地产有限公司**开发的一款面向在日华人、赴日留学生、计划移居日本人群以及日本不动产投资客户的综合型找房与生活服务平台。

我们希望成为短视频与 AI 时代，**100万在日华人的新选择**。

平台以日本找房服务为核心入口，同时围绕日本租房、不动产买卖、投资型不动产、短期租赁、留学、签证、行政书士服务、搬家、装修、车辆买卖等需求，打造覆盖**赴日前、赴日中、赴日后**的综合服务体系。

无论是来日本留学、工作、生活，还是计划在日本购房、投资、长期定居，用户都可以通过日宜找房快速匹配适合自己的房源，并获得后续相关服务支持。

目前，日宜找房已经上线电脑端网站、移动端网站、iOS 客户端、安卓客户端以及微信小程序，并持续进行产品更新与体验优化。

## 四、核心业务板块

### 1. 日本租房服务

**让外国人在日本找房，不只是看到房源，而是真正能够申请、审查、签约和安心入住。**

在日本租房，通常需要经历以下流程：

**找房 → 看房 → 入住申请 → 入住审查 → 签订租赁合同 → 交钥匙 → 入住**

对于外国人和留学生来说，由于语言、身份、收入证明、保证人制度、保证公司审查，以及部分房东和管理公司不接受外国人申请等原因，日本租房往往比想象中更加困难。

常见问题包括：

- 房源已经停止募集，但网上仍然展示。
- 房源不接受外国人申请。
- 留学生或海外申请者难以通过入住审查。
- 不懂日语，无法与管理公司顺利沟通。
- 不理解初期费用、礼金、押金、保证公司费用及退房费用。
- 不熟悉日本租赁合同规则，容易产生不必要的经济损失。

**日宜找房正是为了解决这些痛点而建立。**

平台与日本合作入驻的不动产公司共同筛选房源，优先展示适合外国人、留学生及海外申请者的租赁房源，并提供从找房咨询到入住后的流程协助。

服务重点包括：

- 严格筛选可申请房源。
- 协助确认是否接受外国人、留学生及海外申请。
- 协助整理入住审查材料。
- 提供一对一中文找房服务。
- 协助理解初期费用和合同内容。
- 对接水、电、煤气、网络、搬家等入住后相关服务。
- 入住后继续提供相关咨询支持。

### 2. 日本留学找房服务

**输入学校名，10秒匹配学校附近好房。**

日宜找房通过学校周边找房功能，帮助用户输入学校名称后，快速匹配附近房源，并提供学校距离、车站距离、通学便利度和周边生活环境等参考信息。

平台围绕日本全国47个都道府县的语言学校、专门学校及大学提供学校找房服务。

主要特色包括：

- 输入学校名称，快速匹配附近房源。
- 支持语言学校、专门学校、大学、大学院周边找房。
- 展示房源到学校的大致距离。
- 展示房源到最近车站的距离。
- 推荐学校周边适合居住的车站和区域。
- 支持筛选无礼金、无押金、可商量养宠物等条件。
- 优先推荐可接受外国人、留学生及海外申请的房源。
- 提供区域生活指南及省钱居住区域建议。

在用户抵达日本后，日宜找房还可协助对接搬家、水电煤气开通、手机卡、网络等相关生活服务。

### 3. 短期租赁与民宿服务

为了服务短期来日、临时过渡及尚未完成长期租房申请的人群，日宜找房提供短期租赁、月租公寓、民宿等短期住宿资源。

- 等待长期租房入住的人群。
- 需要临时住所或过渡房源的在日用户。

日宜找房通过自有公寓、合作民宿、月租公寓以及日本全国合作业者，为用户提供更加便捷的短期住宿选择。

### 4. 日本不动产买卖服务

日宜找房为有购房需求的客户提供日本全国范围内的不动产买卖信息与咨询服务。

### 5. 日本收益型不动产与投资服务

日宜找房面向日本不动产投资客户，提供收益型不动产及投资型不动产的筛选与咨询服务。

可覆盖的投资类型包括：

- 一户建投资
- 土地活用
- 店铺

- 商业不动产

- 住宿设施类不动产
- 高尔夫球场及休闲设施类资产

平台可根据客户关注的区域、预算、表面收益率、实际收益率、租赁需求、管理方式和长期持有计划，协助筛选更符合投资目标的房源。

同时对接后续管理、出租、装修及运营等相关服务。

日宜找房在投资型房源详情页中提供投资分析功能，帮助用户更全面地了解投资房源的成本和收益情况。
