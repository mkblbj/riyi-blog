# 日宜房产博客写作手册

## 登录

1. 打开 https://app.pagescms.org/。
2. 点击 GitHub 登录，使用已获授权的日宜房产 GitHub 账号。
3. 打开私有仓库 `riyi-blog`，在左侧选择“文章”。

## 新建草稿

点击“新建”，填写标题、摘要、封面图、一个分类、标签、作者、发布时间和正文。新文章默认是“草稿”；保存草稿会保存在 GitHub，但不会出现在公开网站、搜索、RSS 或 sitemap。

单张图片只能使用 JPG、PNG 或 WebP，大小不得超过 10 MB。正文图片必须填写说明文字；说明文字应描述图片内容，例如“东京一居室客厅”，不要写“图片”。

## 发布和修改

确认正文后，把“状态”改成“已发布”并保存。GitHub Actions 完成后，文章地址固定为 `https://www.riyihome.com/posts/文章编号/`。以后修改标题、分类或发布时间，网址仍然不变。

保存已发布文章会自动重新部署。如果内容没有变化但需要再次发布，点击左侧“重新部署博客”。

## 归档

不再公开的文章应把状态改成“已归档”，不要删除文件。下一次部署会把文章从网站、搜索、RSS 和 sitemap 中移除，GitHub 历史仍然保留。

## 失败提示

部署失败不会替换线上已有版本。常见原因是必填项为空、图片超过 10 MB、封面不存在或正文链接错误。保留文章为草稿并联系维护人员查看 GitHub Actions 日志。
