# 首页 App 下载入口设计

## 背景

日宜房产新官网首页已经承接房产服务、实用内容、查看房源与咨询，但缺少“日宜找房”App 的下载入口。旧官网保存了应用市场地址，新官网需要用现有 Teek 架构重新实现，不能照搬旧页面的悬浮广告与伪二维码。

## 目标

- 在首页首屏之后提供清晰、可发现的 App 下载入口。
- 提供 App Store、Google Play 和微信小程序三种渠道。
- 保持 Teek 主题的明暗模式、响应式布局和交互反馈。
- 不增加后台、数据库或新的云服务依赖。

## 非目标

- 不复制旧官网的大面积蓝色下载区或常驻悬浮条。
- 不展示不能扫描的装饰性二维码。
- 不切换 Teek 当前的博客首页模式。
- 不改造应用发布或小程序后台。

## 方案

新增独立的 `AppDownload` Vue 组件，并通过现有 `teek-home-banner-after` 插槽所在的首页内容链路渲染在服务介绍之前。组件沿用官网内容宽度、绿色品牌色和 Teek/VitePress 主题变量。

下载区包括一段简短说明和三个入口：

1. **App Store**：打开日本区“日宜找房”App Store 页面。
2. **Google Play**：打开“日宜找房”Google Play 页面。
3. **微信小程序**：复制 `#小程序://日宜找房/eFzVt03INd0YNma`，随后使用 Teek `TkMessage` 显示“已复制，请粘贴到微信打开”。复制失败时显示完整口令和人工复制提示。

平台地址集中放在 `src/platform-links.ts`，展示数据放在官方站点数据模块中。组件使用 Teek `TkIcon` 显示平台图标，不引入另一套 UI 框架。

## 响应式与可访问性

- 桌面端为左侧文案、右侧三个入口卡片。
- 移动端按单列排列，按钮保持足够的点击面积。
- 外部应用市场链接在新页面打开，并带 `rel="noreferrer"`。
- 小程序入口使用真实 `<button>`，支持键盘操作和明确的状态文案。
- 明暗模式均使用主题变量控制边框、背景和正文颜色。

## 错误处理

- 优先使用 Clipboard API 复制小程序口令。
- Clipboard API 不可用或被浏览器拒绝时，不声称复制成功；页面显示可选择的完整口令并提示手动复制。
- 应用市场仍保留普通链接，即使 JavaScript 未加载也可使用。

## 验证

- 单元测试先验证平台链接、下载入口数据和复制状态逻辑。
- 站点测试验证首页包含下载区、三个渠道及正确的小程序口令。
- 运行 TypeScript、全部测试、VitePress 构建与产物校验。
- 桌面和移动端浏览器检查首页布局、外部链接与复制反馈。
- 部署后从正式域名验收首页新文案和三条下载入口。
