# 日宜新官网宣传内容整合设计

## 背景与目标

`https://www.riyihome.com`（`riyi-blog`）是日宜的新官网与内容中心，不是附属博客。旧官网 `https://riyi.toiroworld.com/` 仅作为品牌文案和信息结构的参考来源；房源业务平台继续位于 `https://riyihome.com`。

本次改造要让新官网在保留 Teek 内容能力的同时，清楚回答“日宜是谁、提供什么服务、为什么值得了解、下一步去哪里”，并为房源平台和咨询入口提供稳定导流。

## 设计原则

- 保留 VitePress、vitepress-theme-teek、Pages CMS、Markdown 内容与现有 OSS/CDN 部署链路。
- 延续当前深绿色品牌体系和简体中文字体栈，不复制旧官网的蓝色视觉或 React 实现。
- 旧官网只提炼已能合理说明的价值信息，不使用未经验证的用户数量、趋势数据、应用市场状态或二维码。
- Teek 站内搜索继续只搜索官网文章，不伪装成房源搜索。
- 所有外部业务入口集中定义并使用 HTTPS；不使用 iframe，不耦合 uniCloud。
- 桌面端、移动端、浅色模式和深色模式均保持清晰可用。

## 首页结构

1. Teek 导航继续承担文章栏目和“关于日宜”入口。
2. 原 Teek Banner 调整为官网身份：品牌名“日宜房产”，主张“日本找房，就上日宜”，说明官网同时提供找房服务与实用内容。
3. Banner 后增加官网宣传区：
   - 核心服务：日本租房、日本买房、留学安居。
   - 日宜方式：短视频了解房源、结合通勤与生活圈筛选、整理与核验房源信息、按需求持续关注合适房源。
   - 行动入口：查看房源、提交需求、微信咨询。
4. 原 Teek 文章列表保留，并增加“最新房产资讯”标题，使宣传区与内容区的关系清晰。
5. 首页右侧保留作者、精选文章和分类；关闭站点运行时间、字数等偏个人博客的统计卡片。

## 关于页与文章页

“关于日宜”扩充为正式官网介绍，包含：我们是谁、解决什么问题、怎么做、我们相信，以及三个业务行动入口。文案保持可信、直接，不声明无法验证的规模或效果。

文章正文结束后显示统一业务 CTA。它只在文章页面出现，引导读者查看房源、提交需求或微信咨询，不遮挡正文，不使用固定悬浮层。

## 组件与边界

- `src/platform-links.ts` 是外部业务 URL 的唯一正本。
- `HomePromotion.vue` 只负责首页服务、优势和行动区。
- `LatestArticlesHeading.vue` 只负责文章列表区标题。
- `ArticlePlatformCta.vue` 只负责文章末尾导流，并根据 VitePress 页面 frontmatter 判断是否显示。
- `theme/index.ts` 通过 Teek 提供的插槽组合上述组件，不替换 Teek 的内容、搜索或路由实现。

## 验收标准

- 首页首屏明确显示“日宜房产”而非“日宜房产博客”。
- 首页包含三类核心服务、四项日宜方式和三个可访问的 HTTPS 行动入口。
- “最新房产资讯”之后仍显示现有 Teek 文章列表和侧边内容卡片。
- 关于页完整表达官网身份，文章页末尾显示业务 CTA，非文章页不显示该 CTA。
- 不出现旧站 iframe、房源假搜索、未验证数字、无效二维码或 HTTP 业务链接。
- Pages CMS 配置和文章发布流程不受影响。
- `pnpm test`、`pnpm build`、`pnpm verify`、`tsc --noEmit` 和 `git diff --check` 均通过。
